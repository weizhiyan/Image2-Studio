# 原意优先的提示词整理

2026-11-16：节点优化与对话 Agent 默认采用同一套原意优先规则。此前的结构化设计实验仍默认关闭。

## 为什么调整

九图对照中，原文直连的 Logo 与背景保留了更自然的气质。优化器补充的具体造型、颜色和构图没有证明成图收益，反而可能限制生图模型。概念更明确、提示词更长、本地检查通过，都不代表更好看。

## 默认流程

用户原文及必要上下文 → 语言模型整理 → 现有画幅与数值检查 → 生图模型。

- 清楚的单轮需求可以原样提交；短原文原样返回不会因为字数不足被误判失败。
- 保留目的、情绪、使用场景、精确文案、否定要求及已经指定的视觉细节。
- 仅为真实歧义、文案分组、参考图对应、多轮已确认的修改补说明。
- 画幅继续按照原有优先级解析；自动画幅允许按用途选择，不退回统一方形。
- 用户没有具体造型想法时，把目标交给生图模型构思，不强制先列主体、配色、字体、材质、光线和布局。
- 对话将最新修改与已确认上下文合并，不把尚未采纳的历史建议、失败结果或角色模板当成既定要求；不再调用第二个优化器。
- 图1/图2编号、编辑保留项、比例冲突与金额日期检查沿用现有逻辑。

## 三档区别

高遵循尽量保留原句；均衡可以整理必要的上下文与文案；创意允许补充一个简短方向，但不自动指定整套视觉细节。用户已经明确要求的造型、颜色、布局等始终保留。未指定细节交给生图模型不代表限制画面丰富度。

## 验证边界

自动测试检查原文透传、短需求、固定画幅、数值与参考顺序、Agent 单次提交及旧实验兼容。语言模型实测检查实际输出是否仍擅自扩展设计，不执行生图工具。

本轮规则减少的是默认干预，没有新增识别所有语义偏差的程序。语言模型仍可能遗漏或误解；测试通过也不能证明成图优于直连。原文直连继续作为质量基准，成图收益需要同条件看图对照。
